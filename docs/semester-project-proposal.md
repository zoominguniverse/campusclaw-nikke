# CampusClaw 改进版学期项目方案

## 1. 项目题目

**CampusClaw 学伴——基于知识库与教学智能体的班级学习闭环平台**

面向中小学教师和学生，首期聚焦数学学科，在现有 CampusClaw 基础上完善“讲义学习—引导解题—作业批改—错题复习—学情反馈”流程。

## 2. 主要功能

- **用户与权限**：教师、学生分别登录，按班级和学科隔离资源，服务端校验访问权限。
- **讲义知识库**：教师管理讲义，学生检索本班材料；问答附带原文引用，无依据时提示资料不足。
- **教学助手**：结合讲义逐步引导解题，支持流式回答；教师配置助手及技能。
- **作业流程**：教师发布作业，学生提交，系统异步生成批改建议，教师复核并可改分。
- **错题复习**：归集错题、解释错因，推荐同类练习并记录复习结果。
- **学情与审计**：统计提交率和知识点错误分布，记录工具调用、批改与改分操作。

**改进重点**：将问答、作业、错题与学情串成学习闭环，提高回答可追溯性，辅助针对性复习。先完成核心流程，再扩展学情看板与练习推荐。

## 3. 技术方案

| 部分 | 方案 |
| --- | --- |
| 应用与数据 | 延续 Flask、PostgreSQL 和 pgvector，扩展页面、API 与教学业务表。 |
| 大语言模型与 RAG | 服务端调用模型，结合关键词与向量混合检索生成带引用回答；密钥仅保存在服务端。 |
| 智能体与技能 | 根据任务调度解题引导、作业批改、错题讲解三项技能，支持启停、权限校验与调用留痕。 |
| MCP | 接入讲义检索、题目查询、数学计算工具，限制工具白名单、数据范围及执行时间。 |
| 异步任务 | 使用 Redis + Celery 处理索引和批改，支持状态展示、失败重试及防重复执行。 |
| 开发与部署 | 采用 OpenSpec 规约驱动开发；Docker Compose 部署至公网并配置 HTTPS，使用 pytest 与浏览器测试验收。 |

AI 批改先生成建议，正式成绩由教师确认。验收覆盖跨班访问、技能停用、资料无命中、模型超时与工具失败等场景。

**交付成果**：公网可访问系统、源码、OpenSpec 规约、部署说明及测试报告；演示讲义上传、引导问答、作业提交、批改复核和错题复习的完整流程。
