# 教师技能文件

样板位于 `backend/tutor_samples/mathematics.txt` 和 `backend/tutor_samples/language.txt`。教师可直接上传 UTF-8 文件或粘贴全文编辑。中文键行位于元数据区，空行以后是说明；支持英文或中文冒号，元数据区的 `#` 注释忽略。

名称（最多32字）、适用条件（120字）、启用（是/否）必填。资料是可选的材料标题子串，最多32字；工具可省略，只支持 `knowledge_search`。说明非空、最多2000字，全文件最多8000字。适用条件按中英文逗号、顿号、分号和竖线分词，子串命中计分，平分取较小技能ID；只从助手绑定且启用的技能中选至多一条。

名称含“解题引导”时只给下一步检查，不给最终得数、选项、诗句或完整解法。实际模型行为须通过真实审阅，样板解析通过不代表引导行为验收已通过。上传不会执行脚本或调用任意工具。每轮必先检索助手绑定材料与用户权限的交集，工具字段省略也不跳过此步骤。

技能原文按提交内容保留；重复、未知字段、缺少正文和非法工具返回400，并且不写数据库。删除技能会解绑助手，但已有会话记录保留。技能改写、停用或解绑在下一轮生效。
