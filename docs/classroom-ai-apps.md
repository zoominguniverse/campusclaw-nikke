# 在线课堂应用与提示词模板

每班新增课堂备课助手、随堂测验助手、课堂讨论主持和课后复习教练。与原有数学、语文助手一起覆盖六类教学场景。新助手不自动绑定材料或工具，教师可在“智能体与技能”页按学科权限补充绑定。

教师在配置页选择六项内置模板，填写学科、年级、课题、课堂时长，点击“预览模板”查看完整提示词；点击“应用到角色提示词”仅填写当前表单，仍需“保存智能体”才生效。可继续自由编辑。应用模板保留当前技能和材料选择。

变量 subject/grade/topic/minutes 使用单次字面替换，不执行表达式。模板接口仅允许当前班级教师，未知变量或非法时长返回400。模板目录是受版本管理的内置目录，不含用户自定义模板CRUD；保存后的角色提示词沿用智能体审计和下轮生效规则。

默认教学应用在显式演示种子模式下幂等增加；重复启动不覆盖教师修改过的名字、提示词、启停或绑定。课堂助手对本班师生可见，其中备课模板面向教师使用。

MCP 工具助手另以本班 school 服务器的 formula_hint、unit_convert 提供公式与单位检查。教师须完成连接、声明审阅、技能绑定；工具由模型决定是否调用，宿主重新授权并记录审计。正常环境的实际启用情况与验收结果见[本次运行记录](classroom-mcp-acceptance/README.md)。
