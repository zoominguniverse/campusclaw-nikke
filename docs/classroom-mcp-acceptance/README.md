# 课堂应用、提示词模板与主环境 MCP 启用验收

日期：2026-10-27（Asia/Hong_Kong）。主项目使用根目录 Compose、Gunicorn、正常 PostgreSQL 和现有真实模型，非测试部署。

## 已交付

- 每班新增课堂备课助手、随堂测验助手、课堂讨论主持、课后复习教练；保留原语文、数学助手，再增加课堂工具助手，当前三班各 7 项，共 21 个启用助手。
- 教师可选择六项内置角色模板，填写学科、年级、课题、课堂时长，预览并应用为可编辑角色提示词。保存仍走现有权限、审计和下轮生效机制。
- 配置主环境 MCP_ENABLED=true，生成独立 Fernet key 和服务令牌，只存于忽略的 .env。部署许可仅为 http://mcp-demo:8090 的 formula_hint、unit_convert 两项 read 权限。
- 三班分别登记 school、连接发现两项完整声明，并保存声明确认；各有独立的课堂工具解题引导技能和课堂工具助手。新工具助手不绑定知识库，不扩大资料访问权限。

## 运维与边界

升级前已备份数据库与旧私有环境到忽略的 `.retrieval-backups/classroom-20261027/`，未重置数据库、材料或上传卷。使用默认工具阶段预算和既有班级、会话归属规则。内置模板目录受代码版本管理，当前未提供用户自建模板条目的CRUD。

可在根目录运行 `python backend/configure_classroom_mcp.py` 检查/配置固定的本地 classroom MCP 入口；该命令会通过正常 API 登录、连接发现并保存技能确认，保留编辑过的同名技能。`--verify-real` 会额外创建两组真实对话并产生模型用量，重新执行前需相应数据和出站授权。脚本不会将凭据写入报告。

关闭 MCP 时在本地 .env 设置 MCP_ENABLED=false 并重建 API，保留已登记服务器、加密密钥、技能、历史和审计；重新启用可恢复。该配置仅对当前主环境生效；远端仓库不包含可用密钥，其他部署须自行配置。
