## 行为及内容审阅

| 样例 | 实际决策/审计 | 最终辅导审阅 |
| --- | --- | --- |
| no_call | 1次决策，模型返回零调用，0次远端尝试 | “你想先检查哪里？”符合用户先表达想法的要求，未擅自调用工具 |
| choose | 首轮选 `formula_hint`，query 包含 `2-(3+x)` 和括号前减号；收到结果后停止；1条 ok | 提醒检查减号，要求学生写出去括号的下一步；没有直接给出化简结果 |
| dependent | 第1轮 `formula_hint`；第2轮收到相关联 role:tool 后才生成 `unit_convert` 参数；两条 ok，round 为1、2 | 只提示先处理去括号并问括号前是什么符号；没有计算最终结果或一次给出整题答案 |
| remote_failure | 1次远端调用被401拒绝，审计 error/remote_unauthorized；模型收到错误结果后停止工具；失败仍计1次额度 | 继续提示减号下的符号处理并让学生判断各项符号，未声称工具成功，未输出最终化简答案 |
| budget | 轮次上限设为1；模型首轮同时提议两个工具，宿主顺序执行两条 ok；随后结束工具阶段并发送 tool_warning，没有第2次决策 | 最终流正常 done，只让学生先找出括号前的符号，没有最终答案 |

预算样例证明达到轮次上限后停止后续决策并继续辅导。它没有证明“第二个同轮工具被拒绝”：本次首轮有两个提议，两者都在允许的每问尝试额度内，实际均执行。每问远端次数、会话累计次数和时间上限由已有隔离测试另行覆盖，不能把这些结果归入本次真实模型样例。

依赖样例第2次 query 实际包含：

> 承接上一步去括号检查提示（先看括号前符号，减号要每一项变号，乘数要乘到每一项），这一步是单位换算，请说明米与厘米的关系和换算方向，不要把去括号与单位换算混在一起

第2次请求内的 role:tool/tool_call_id 与第1次响应调用ID对应，说明参数在接收第一轮结果之后形成。请求快照在调用适配器之前深复制，防止后续消息追加改写早先证据。
