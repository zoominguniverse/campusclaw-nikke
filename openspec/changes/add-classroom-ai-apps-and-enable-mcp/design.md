## Context

复用 Flask/Jinja、原生 JavaScript、TutorAgent.prompt 和现有种子逻辑。模板不新增数据库表。主配置已有 MCP 容器与权限、加密、审计能力，但私有环境未启用。

## Decisions

- 用静态受版本管理的六项目录提供模板，四项为本次新增课堂应用，另两项覆盖原学科助手。模板有 subject/grade/topic/minutes 四个有界变量，使用单次正则字面替换，默认值使新种子可直接使用。
- 增加班级作用域的教师目录读取和渲染接口，渲染结果写入现有表单；保存仍走原 agents 接口。模板渲染不调用模型。
- 新应用按班级使用 seed_key 幂等创建；不覆盖旧记录，不自动绑定全班知识库或工具。
- MCP 只许可 Compose 内部 origin 的 formula_hint/unit_convert。独立生成 Fernet key 和服务令牌到 .env，在各班登记 school 并通过现有 API 完成发现、声明确认、技能绑定和工具助手配置。
- 验收保留普通主环境。用户已授权两组不绑定知识库的合成问题发送至 DeepSeek，由真实模型决定调用；留档仅脱敏参数、结果和审计对应关系。

## Verification and rollback

模板验证覆盖教师权限、变量长度/未知字段、字面替换和种子幂等；前端核对预览/应用的实际操作。运行前备份正常库；MCP 可通过本地开关关闭而保留表与审计。代码回退不删除新建助手。私有凭据和完整环境不进入报告。
